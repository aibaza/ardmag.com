# Insigna de reducere pe cardul de produs — 3 propuneri (neimplementate)

Mockupuri pe cardul real (Mastic Lichid, preturi reale din catalog: 64,00 Lei, inainte 80,00 Lei, -20%), randate local cu Playwright la 1440 si 390. Starea de azi: `actual-*.png`.

- **A — insigna mare pe imagine** (`propunere-A-*.png`): aceeasi insigna din colt, dar de ~2x (20px, bold, umbra usoara), cu pretul nou colorat si cel vechi taiat; cea mai mica schimbare, tiparul clasic al magazinelor de moda si casa.
- **B — reducerea langa pret** (`propunere-B-*.png`): insigna pleaca de pe imagine si sta langa pret, cu pretul vechi taiat si „Economisești 16,00 Lei”; urmeaza cercetarea Baymard ca oferta se intelege cand sta grupata langa pret.
- **C — banderola pe imagine** (`propunere-C-*.png`): banda pe toata latimea, la baza imaginii, „-20% PREȚ REDUS”, plus pretul colorat si cel vechi taiat; cea mai vizibila in grila, se vede de la distanta.

Surse: [Baymard — discounturi pe pagina de produs](https://baymard.com/blog/product-page-price-discounts), [Baymard — 10 practici UX pentru reduceri](https://baymard.com/blog/10-sales-ux-best-practices), [Baymard — badge-uri UI](https://baymard.com/blog/badge-ui), [ecommerceguide — tiparul price promo](https://ecommerceguide.com/patterns/price-promo/), [Google Merchant — adnotari de pret redus](https://support.google.com/merchants/answer/9017019).
